# 🌸 3rd Monthsary Website

A fully interactive, multi-page love website built with HTML, CSS, and JavaScript.

## ✨ Features

- **Home Page** — Animated photo stack, floating hearts, pull-the-string surprise note, animated counters
- **Letter Page** — Tap-to-open envelope with fold animation, handwritten-style letter
- **Gallery Page** — Full photo grid with lightbox, keyboard navigation, tilt hover effect
- **Why I Love You** — Flip cards with 12 reasons, shuffle animation
- **Our Story** — Scroll-reveal timeline with photos
- **Global** — Falling petal canvas, cursor heart trail, mobile swipe navigation, ambient music toggle

## 📁 File Structure

```
/
├── index.html        ← Main website (all pages)
├── style.css         ← All styles & animations
├── script.js         ← All interactions & effects
├── images/           ← Your photos
└── README.md
```

## ✏️ How to Edit the Letter

Open `index.html` and find the section marked:
```html
<!-- EDIT THIS TEXT -->
```
Replace the paragraphs with your own words. Look for `[Write your personal paragraph here...]` and `[Your Name]`.

## ✏️ How to Edit the Timeline

In `index.html`, find the timeline section and replace:
- `[Edit: Describe how it all started...]`
- `[Edit: A special memory from month two...]`
- `[Edit: Where you are now...]`

## 🚀 Deploy to GitHub Pages (Free!)

1. Create a new GitHub repository (e.g. `3rd-monthsary`)
2. Upload all files — **include the `images/` folder**
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)` → **Save**
5. Your site will be live at: `https://YOUR-USERNAME.github.io/3rd-monthsary/`

> ⏱ It may take 1–2 minutes to go live after saving.

## 💡 Tips

- Make sure all image files stay inside the `images/` folder
- The site works on mobile too — swipe left/right to navigate pages
- Click the 🎵 button (bottom right) for soft ambient music
- Pull the string on the home page for a surprise!
